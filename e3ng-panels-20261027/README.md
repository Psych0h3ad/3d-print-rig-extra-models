# E3NG v1.2 rear electronics panels

RH3D's official hex-pattern panels from the public E3NG v1.2 EXTRAS files,
revision 2024-08-16. Sources, file identities and hashes are in sources.json.

https://www.printables.com/model/922401-ender-3-ng-v12-corexy-conversion

CC BY-NC-SA 4.0 applies to the source panels and their adapted meshes.

The Web model preserves all source STL triangles, uses lossless indexed
geometry and rigid placement, and omits no supports. Each panel follows the
printed base color. The optional dual-color printing process is not simulated.
This is a visual assembly reference, not a certification of an entire build.
