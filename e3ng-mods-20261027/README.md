# E3NG v1.2 community modifications

Web meshes of Synthead’s reinforced toolhead base and cable-hole mount for RH3D’s E3NG v1.2. Original public author files, exact source versions and hashes are listed in [sources.json](sources.json).

Authors: Synthead and RH3D. License: [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). The same license applies to these adapted meshes. Attribution, noncommercial and ShareAlike conditions remain applicable.

Changes: tessellated the public community STEP files for the viewer and applied rigid mounting transforms. No source CAD solids were reshaped. No built-in supports were identified or removed from these two community parts.

These are two optional printed replacements. The original E3NG assembly, hardware and motion controllers remain separate. Mesh and selected mounting-datum checks do not certify an entire physical build.
